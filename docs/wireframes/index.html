Regras que valem para as jornadas

  • Mobile first: uma coluna no celular; listagens ganham colunas a partir de 640 px.
  • Uma ação principal por tela (laranja); ações de doação em verde.
  • Login só quando precisa (checkout, pedidos, conta); o carrinho do visitante vai junto.
  • Regras detalhadas da compra para o abrigo: docs/compra-para-o-abrigo.md (KAN-12).
